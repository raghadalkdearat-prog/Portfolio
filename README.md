# Portfolio


## About The Project
This is a personal, fully responsive portfolio website designed and developed to present my profile, software development skills, and technical projects. Built using modern HTML5, custom CSS3, and Bootstrap 5, the website offers a smooth user experience across all devices and highlights my professional journey, qualifications, and references.


## Tech Stack:
- **HTML5:** For the page structure and elements.
- **CSS3:** For custom colors, layout design, and responsiveness.
- **Bootstrap 5:** For the navbar, footer, and responsive layout.
- **Bootstrap Icons:** For social media icons.
- **Google Fonts:** For custom typography (*Fira Code* & *Convergence*).
- **Git & GitHub:** For version control and hosting.


## Sections:
- **Navbar:** Fixed top navigation for quick access to all sections.
- **Home:** Introduction, profile picture, and CV download button.
- **About Me:** Personal background, software development focus, core coding philosophy, and work availability status.
- **Experience:** Overview of my frontend development and UI/UX background.
- **Qualifications:** Academic degree and certifications.
- **Skills:** Displaying my technical and soft skills.
- **Projects:** Cards showing my GitHub projects with direct links.
- **References:** Links to professional LinkedIn profiles.
- **Footer:** Social media links and copyright information.
